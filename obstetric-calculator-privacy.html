Kebijakan Privasi

Terakhir diperbarui: 12 Juli 2026

Selamat datang di Dr. Sapto ObstetriCalc. Kebijakan Privasi ini dibuat untuk menjelaskan aturan pengolahan data Anda saat menggunakan layanan aplikasi kami.

1. Pengumpulan dan Penggunaan Data

Di DR SAPTO LABS, kami sangat menghargai privasi dan kerahasiaan medis Anda. Aplikasi ini tidak mengumpulkan, tidak menyimpan, dan tidak membagikan data klinis, identitas pasien, usia kehamilan, HPHT, berat janin, atau hasil perhitungan medis apa pun ke server eksternal kami maupun pihak ketiga.

Seluruh proses kalkulasi klinis dilakukan secara **100% lokal offline di perangkat Anda**. Data perhitungan tidak pernah meninggalkan perangkat Anda kecuali jika Anda memilih untuk membagikannya secara manual.

2. Izin Perangkat (Permissions)

Aplikasi Dr. Sapto ObstetriCalc dirancang secara minimalis dan mandiri:

  • Tidak memerlukan akses GPS / Lokasi.
  • Tidak memerlukan akses Kamera atau Galeri foto.
  • Tidak memerlukan koneksi internet untuk melakukan kalkulasi klinis.

3. Layanan Pihak Ketiga

Aplikasi ini sepenuhnya bersih dan mandiri. Kami tidak menanamkan SDK analitik, pelacakan iklan, atau integrasi pihak ketiga eksternal yang dapat merekam aktivitas penggunaan klinis Anda.

4. Retensi Data

Karena kami tidak memiliki server penampung dan tidak pernah mengumpulkan data Anda, kami tidak memiliki data medis Anda untuk dihapus atau disimpan. Riwayat input kalkulasi yang terekam di layar akan langsung hilang saat aplikasi ditutup/dibersihkan dari memori RAM perangkat oleh sistem operasi.

5. Keamanan

Karena seluruh pemrosesan data medis dilakukan secara lokal dan offline, risiko kebocoran data akibat peretasan siber eksternal atau penyalahgunaan database dapat diminimalisir secara total.

6. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini sewaktu-waktu. Setiap pembaruan kebijakan baru akan dipublikasikan di halaman situs web ini.

7. Hubungi Kami

Jika Anda memiliki pertanyaan atau masukan mengenai Kebijakan Privasi ini, silakan hubungi kami di: drsapto.labs@gmail.com.
